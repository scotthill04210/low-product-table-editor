# Changelog

## 1.1.0

* CSV export and import matched on SKU.
* Preview, chunked apply, audit log source Import, and undo for import batches.

## 1.0.0

* Edit products and variations in one table, including 4-decimal prices and Sold By.
* Save through WooCommerce, with an audit log, bulk price changes, and conflict-safe undo.
* Keyboard shortcuts, focus indicators, and error states that keep unsaved edits when the session expires.
* Release package excludes docs, tools, and git files.

## 0.1.1

* First published build: plugin scaffold and GitHub updates. The table editor was not in that zip.
